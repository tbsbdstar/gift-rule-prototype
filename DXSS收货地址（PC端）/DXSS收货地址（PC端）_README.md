# DXSS 收货地址（PC 端）— 原型说明

> MARUONE 会员商城（网页端）结算页「新增日本收货地址」交互原型

---

## 一、整体功能说明

Web 会员商城**结算页**中的**新增日本收货地址**面板，用于用户在下单结算时新增/管理日本收货地址。

**核心功能：**

| 模块 | 说明 |
|------|------|
| 👤 收货人信息 | 收货人姓名（支持中/日 お名前）、手机号（可填日本或中国手机号） |
| 〒 邮编 / 町域 | 按日本邮编带出町域等地区信息 |
| 🏠 详细地址 | 丁目・番地（例：1-1-1）等详细地址 |
| ⭐ 默认地址 | 「设默认」设为默认收货地址、支持删除 |
| ✅ 确认新增 | 「确认新增」保存地址并用于结算 |
| 🛒 商城结算上下文 | 页面处于会员商城结算页内，顶部含商品搜索等商城框架 |

> 说明：本页为**前端交互原型**，内置示例/地址数据，用于演示界面与交互流程。
