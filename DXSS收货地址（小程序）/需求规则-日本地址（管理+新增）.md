# 日本收货地址（管理 + 新增/编辑）需求规则说明

> 适用页面：`（日）地址管理.html`、`收货地址页（日）.html`（丸噗噜小程序 · 日本地址）
> 说明：本文档描述交互原型所体现的功能与规则，供需求评审/开发参考。数据为前端本地演示（localStorage），不含真实后端。

---

## 一、概述与页面关系

面向小程序用户的**日本收货地址**录入与管理能力，由两个页面构成：

| 页面 | 定位 | 说明 |
|------|------|------|
| `收货地址页（日）.html` | **主流程页（列表 + 新增/编辑 合一）** | 页面内含「列表视图」与「新增/编辑视图」两态，按钮切换；自成闭环 |
| `（日）地址管理.html` | **独立列表管理页** | 仅列表；「＋新增 / 编辑」跳转到 `收货地址页（日）.html` |

> 两页共享同一份本地数据，行为规则一致。下文规则对两者通用，差异处单独标注。

---

## 二、数据与通用规则

- **存储**：浏览器 `localStorage`，键名 `addr_jp_only`，值为地址对象数组（JSON）。
- **单条地址字段**：

  | 字段 | 含义 | 备注 |
  |------|------|------|
  | `id` | 唯一标识 | 新增时用时间戳生成 |
  | `ts` | 创建/更新时间戳 | 用于列表排序 |
  | `country` | 国家 | 固定 `jp` |
  | `name` | 收件人 / お名前 | 必填 |
  | `telCC` | 手机号国家区号 | `081`=日本、`086`=中国 |
  | `tel` | 手机号 | 必填，可填日本或中国号码 |
  | `zip` | 郵便番号 | 7 位，展示为 `XXX-XXXX` |
  | `pref` / `city` / `town` | 都道府県 / 市区町村 / 町域 | 町域可选 |
  | `detail` | 丁目·番地（详细地址） | 必填 |
  | `bldg` | 建物·部屋（楼名·房号） | 必填 |
  | `def` | 是否默认地址 | 布尔 |

- **默认地址规则**：全列表**至多一个**默认地址。将某条设为默认时，自动清除其他默认。
- **演示数据**：首次打开注入若干条示例地址；示例版本号（SEED_VER/SV）变更时自动重置一次演示数据。

---

## 三、列表 / 地址管理 规则

**展示项（每条卡片）**：受取人（含「默认」标签）、電話番号（区号+号码）、郵便番号（`〒`前缀）、住所（都道府県+市区町村+町域+丁目番地+建物 拼接）。

**排序**：默认地址置顶，其余按时间倒序（新→旧）。
> 注：`收货地址页（日）` 的列表视图按上述规则排序；`（日）地址管理.html`（独立页）按数据数组顺序展示。

**操作**：
| 操作 | 规则 |
|------|------|
| 设为默认 | 单选圆点。点击后该条变默认，其余取消默认 |
| 编辑 | 进入编辑态并预填该条数据（`收货地址页（日）`内切换到表单视图；`（日）地址管理`跳转 `收货地址页（日）.html?edit=<id>`） |
| 删除 | 二次确认「确定删除该地址？」后移除 |
| ＋新增 | 进入空白新增表单（`收货地址页（日）`内切换；`（日）地址管理`跳转 `收货地址页（日）.html`） |

**空状态**：无地址时显示「📭 还没有收货地址／点击下方按钮新增」。

## 四、新增 / 编辑表单 规则（收货地址页（日）·表单视图）

本页表单**固定为日本地址**（进入即 `switchRegion('jp')`）。

### 4.1 字段与必填

| 字段 | 必填 | 规则 / 提示 |
|------|:---:|------|
| 收件人（お名前） | ✅ | 空则提示「请填写 お名前(姓名)」 |
| 手机号（電話番号） | ✅ | 可切换区号 `081 日本 / 086 中国`；空则提示「请填写 電話番号」 |
| 郵便番号（zip） | — | 7 位数字，输入即触发邮编联动（见 4.2）；展示格式 `XXX-XXXX` |
| 所在地区（都道府県/市区町村/町域） | ✅ | 必须选到**都道府県 + 市区町村**（**町域可选**）；否则提示「请选择 都道府県 / 市区町村（町域可选）」 |
| 丁目·番地（detail） | ✅ | 空则提示「请填写 丁目·番地」 |
| 建物·部屋（bldg） | ✅ | 空则提示「请填写 建物·房号」 |
| 设为默认 | — | 开关；新增时默认打开 |
| 地址预览 | — | 随输入实时拼接预览完整地址 |

### 4.2 郵便番号 ⇄ 地区 双向联动

- **邮编 → 地区**：输入 7 位邮编后自动带出都道府県/市区町村/町域。
  - 优先本地邮编索引（内置 KEN_ALL 数据）匹配；
  - 未命中则回退**在线查询**（zipcloud：`zipcloud.ibsnet.co.jp`）；
  - 状态提示：命中「已根据邮编带出：…」；未命中「未找到该邮编对应地区」；网络失败「邮编查询失败(请检查网络)」。
- **地区 → 邮编**：选完地区后回带邮编；
  - 能确定则「已由所选地区带出邮编」；
  - 若该町域邮编需后端提供，则提示「该町域邮编需后端(KEN_ALL)提供」。

### 4.3 地区级联选择

- 日本：**逐级列表**选择 `都道府県 → 市区町村 → 町域`，支持关键词搜索，长地名整行显示，町域可「跳过·不选」。
- （表单亦保留中国大陆级联 `省 → 市 → 区/县` 的逻辑，本页固定日本，一般不触发。）

### 4.4 保存

- 校验通过后组装地址对象（见二·字段），写入 `addr_jp_only`：
  - 若「设为默认」开启 → 先清除其他默认；
  - **编辑模式**（`?edit=<id>` 或从列表进入）→ 覆盖原记录；**新增** → 追加。
- 保存后返回列表（`收货地址页（日）` 内切回列表视图；从 `（日）地址管理` 跳转来的场景则回到该管理页）。

### 4.5 编辑模式入口

- URL 带 `?edit=<id>`：按 id 从本地读取并预填表单；找不到则回退为新增。
- 页内从列表点「编辑」：直接切到表单视图并预填。

## 五、页面跳转关系

```
（日）地址管理.html
   ├─ ＋新增   → 收货地址页（日）.html
   └─ 编辑     → 收货地址页（日）.html?edit=<id>

收货地址页（日）.html （列表视图 ⇄ 表单视图，页面内切换）
   ├─ ＋新增   → 表单视图（空白，默认开关打开）
   ├─ 编辑     → 表单视图（预填）
   ├─ 保存     → 校验→写入→回列表视图
   └─ 返回‹    → 列表视图
```

---

## 六、边界与异常

- 邮编在线查询依赖网络，失败时给出明确提示，不阻断手动选择地区。
- 删除为二次确认，防误删。
- 默认地址唯一性由「设为默认/保存默认」逻辑保证。
- 本原型数据存本地浏览器，换浏览器/清缓存会重置为演示数据；正式版应由后端地址簿接口承载。
